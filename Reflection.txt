Assignment 6 Reflection

In this assignment, I practiced using one-dimensional and two-dimensional arrays in Java. The weekly spending program helped me understand how to store multiple values in one array and use loops to calculate a total, an average, and the highest amount. The movie theater program was a little more challenging because I had to work with rows and columns in a two-dimensional array. One challenge was remembering that the user enters seat numbers starting at 1, but array indexes start at 0. I handled this by subtracting 1 before accessing the array and checking whether the row and seat numbers were valid. I also used smaller methods to keep both programs organized and easier to test. Overall, this assignment helped me feel more comfortable using arrays, loops, and methods together.
